# Deathventory player information

Small static placeholder pages for **Deathventory: Ember Road**. No game source or assets are included.

Hosted with GitHub Pages from the root of `main`:

- Home: https://growlite.github.io/deathventory-support/
- Privacy: https://growlite.github.io/deathventory-support/privacy/
- Support: https://growlite.github.io/deathventory-support/support/

## Status

These are explicitly labelled placeholders, not a completed privacy policy or release-ready support site. The pages request search engines not to index them while unfinished. There is no JavaScript, contact form, analytics integration, external font or build step in this repository.

Before App Store submission:

1. Replace the privacy notice with the reviewed policy matching the final game and hosting setup, including the privacy contact.
2. Add the approved public support contact and useful help content.
3. Review both English and Spanish text.
4. Remove `noindex,nofollow` when the pages are ready for discovery.

The game’s `sfx_source` and `music_source` credits still require accurate provenance; this repository does not supply or guess them.

## Editing

Edit `index.html`, `privacy/index.html`, `support/index.html` and `styles.css`. Push to `main`; GitHub Pages republishes the site. The `.nojekyll` file keeps these files buildless.
